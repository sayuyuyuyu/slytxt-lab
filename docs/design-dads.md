# 基本デザインと DADS の差分（#854）

デジタル庁デザインシステム（DADS）の Foundations を基準に、このサイトの「基本部分」（タイポグラフィ・余白・色・基本部品）の現状との差分をまとめる。サイト固有の表現（フィードのカード、記事の装飾、ターミナル風の見た目）は対象外。

参照した DADS のページ:

- タイポグラフィ（概要・テキストスタイル一覧）: 本文 16px 以上、14px は付随情報のみ、14px 未満は使わない。行高は 140〜175%。
- 余白: 8 CSS px を基準単位にしたスケール。見出し前は 40〜64px、見出しと本文の間は 16〜24px。
- アクセシビリティ: コントラスト比（WCAG 2.2）、フォーカスインジケーター（4px のアウトライン＋内側のリング）。

## 差分と対応

| 項目 | 変更前 | DADS の基準 | いまの状態 | 残り |
| --- | --- | --- | --- | --- |
| 本文の文字サイズ | 1rem（16px） | 16px 以上 | 1rem（16px）で基準を満たす | — |
| 本文の行高 | 1.8 | 140〜175% | 1.8（範囲内） | — |
| 小さい文字 | 0.66〜0.85rem（10.5〜13.6px）が多数 | 14px 未満は使わない | 0.875rem（14px）を下限に統一（テストで見張る） | — |
| 見出しのスケール | 場当たりの clamp | Std-14〜36 のスケール | ページ見出し 28〜36px、一覧見出し 24〜28px、記事 h2 24px | h3・h4 の微調整 |
| 余白 | 12/14/18/22px などの直値 | 8px 基準のスケール | `--space-1`〜`--space-7`（8〜64px）を定義し、主要ブロックに適用 | カード内・フォーム部品の置き換え |
| 文字色・リンク色 | 青系 | 4.5:1 以上 | パレット（#855）で text 12.4 / muted 4.8〜5.9 / accent 7.3〜7.9（テストで見張る） | — |
| フォーカス表示 | 2px の単色アウトライン | 太さ 2px 以上のリング＋3:1 | 2px のテキスト色アウトライン＋4px のアクセントリング | コンポーネント固有の focus 指定の整理 |
| ボタン・リンクの基本形 | 独自クラス | DADS の Button / Link | 独自の見た目を保つ（判断は下記） | 別 Issue（揃えるなら） |
| ターゲットサイズ | 44px のボタンあり | 24px 以上（推奨 44px） | 主要操作 44px、タグ 32px（AA の 24px は満たす） | 推奨 44px に揃えるかは未決 |

## これまでの対応

- 文字サイズのトークン（`--text-*`）と余白のトークン（`--space-1` 〜 `--space-7`）を追加。
- 14px 未満だった文字サイズを 0.875rem（14px）へ、13〜15px 帯を 14〜16px へ寄せた。
- ページ見出しと記事 h2 を DADS のスケールに合わせた。
- フォーカス表示を二重リングにした（パレットに黄色が無いため、内側はアクセント色）。
- （#854）文字サイズのトークンを DADS の Standard スケール（14 / 16 / 18 / 20 / 24 / 28 / 32 / 36px）に揃え、15px と 30px を消した。一覧見出しの clamp と本文まわりの直値（1.2rem / 1.1rem / 1.03rem）もトークンに寄せた。
- （#854）余白を、値が一致する主要ブロック（`.page-header` / `.section` / `.entry-card` / `.listing` / フッター）で `--space-*` に置き換えた。
- （#854）`tests/design.test.mjs` を追加し、次のずれを機械で見るようにした。
  - 文字サイズが DADS のスケールに載っていること、14px 未満を使っていないこと。
  - 本文・リンク・補助文字・状態色（注意／警告）のコントラストがダーク・ライトとも 4.5:1 以上あること。
  - フォーカス表示が 2px 以上のアウトライン＋内側リングを持つこと。

## まだ残っていること

1. 余白のトークン化は主要ブロックだけ。カード内の細部やフォーム部品は直値が残っている。
2. ボタン・リンク・フォーム部品の基本形を DADS の作法に揃えるかは未決。いまはサイト独自の見た目（2px の角、モノスペース）を保っている。DADS の Button は角の形状と状態色をコンポーネント単位で決める前提なので、揃えるなら別 Issue で扱う。
3. ターゲットサイズは主要操作が 44px、タグが 32px（WCAG 2.2 AA の 24px は満たす）。DADS の推奨 44px に揃えるかは未決。
4. 罫線（`--border` / `--border-strong`）は装飾として扱い、3:1 の対象外にしている。入力欄など「境界が無いと部品と分からない」箇所を作るときは、その部品だけ 3:1 を確保する。
